# Kagiso Matlakaneng - Developer Portfolio

A responsive, single-page portfolio starter built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in your browser, or use VS Code's Live Server extension.
3. Edit content in `index.html` and styles in `styles.css`.

## Before publishing
- Replace the GitHub profile links if your username or profile URL changes.
- Replace the generic GitHub links in project cards with the exact repositories.
- Add the real live URL for CyberSA Learn if you want recruiters to try it.
- The résumé is available as `assets/Kagiso_Matlakaneng_Junior_Resume.pdf` and linked from the navigation and contact section.
- Confirm dates and project descriptions accurately reflect your experience.
- Remove or change any statement that does not match your current CV.

## Deploy on GitHub Pages
1. Create a new public GitHub repository, for example `kagiso-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, the `assets/` folder (including your résumé PDF when added), and this README.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will provide the public URL after deployment completes.

This is a static website, so it does not require a backend server or paid hosting. Google Fonts requires an internet connection; the site otherwise uses local files.

## Adding your résumé
The current résumé is in `assets/Kagiso_Matlakaneng_Junior_Resume.pdf`. To replace it, keep that filename or update both résumé links in `index.html`.

## Adding future projects
Duplicate one of the `<article class="project">` blocks in `index.html`, then update its title, description, tags and project links. Replace the “In development” text as projects are completed.
